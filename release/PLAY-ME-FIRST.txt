STATELINE: CAMPAIGN TRAIL — Alpha 0.1.0  (Windows 64-bit)
=========================================================

HOW TO RUN
----------
1. Keep BOTH .exe files together in this folder.
2. Double-click  Stateline.exe

If Windows SmartScreen appears ("Windows protected your PC"):
   click "More info" -> "Run anyway".  (Unsigned indie build, not malware.)

IF Stateline.exe DOES NOTHING (no window appears)
-------------------------------------------------
Run  Stateline.console.exe  instead. It opens a black console window and
prints WHY the game couldn't start (graphics driver, a blocked file, etc.).
Send me that console text and I'll fix it fast.

Also worth a 10-second check:
 * Right-click Stateline.exe -> Properties. If there's an "Unblock" checkbox
   at the bottom, tick it and click OK, then try again.
 * Confirm Stateline.exe is about 109 MB (109,839,640 bytes). If it's smaller,
   the download/join was incomplete — grab it again.
 * Windows Defender occasionally quarantines unsigned game exes. If Stateline.exe
   vanishes after you run it, that's Defender — check Protection History and
   "Allow" it, or add an exclusion for this folder.

WHAT IT IS
----------
Create a candidate, pick a race, run the campaign week by week (ads, rallies,
ground game, fundraisers), survive the dilemmas, then play out a live election
night. You start as the underdog — buy name recognition before you persuade.
Settings (volume / music / reduced motion) are on the title screen.
