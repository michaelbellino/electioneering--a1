STATELINE: CAMPAIGN TRAIL — Alpha 0.3.1 (Windows 64-bit)
========================================================

SETUP
-----
Keep all three files in ONE folder:
    Stateline.exe          the engine runtime  (never changes between versions)
    Stateline.console.exe  same, but prints errors to a console if it won't start
    Stateline.pck          THE GAME            (this is the only file that updates)

Double-click Stateline.exe.
SmartScreen ("Windows protected your PC") -> More info -> Run anyway.
No window? Run Stateline.console.exe and send me what it prints.

UPDATING FROM NOW ON
--------------------
You only need the new Stateline.pck (~0.7 MB). Drop it in, replacing the old
one, relaunch. No more 38 MB downloads and no more joining split files —
the .exe is the stock Godot runtime and is byte-identical in every build.

WHAT'S NEW IN 0.3.1 — NEW LOOK
------------------------------
* Rebuilt the interface as a clean, light, modern sim UI (Democracy 4 /
  Subway Builder territory) instead of the dark dashboard look.
* Real typography: Public Sans (the US government's own open typeface) for
  text, Oswald for headings, Courier Prime for money and tallies.
* Warm light palette, clearer selection states, chunkier controls, and the
  data is now the brightest thing on screen instead of the chrome.

0.3.0 — THE PRECISE PLATFORM (the big gameplay addition)
--------------------------------------------------------
Your platform is 24 CONCRETE POLICY STANCES, not 8 vague sliders.
* Open any issue area on step 3 to reveal the named policies under it —
  universal background checks, drug-price negotiation, carbon pricing,
  sentencing reform, border enforcement, and 19 more.
* Each has a WEIGHT (how much it moves the area) and a POLLING OFFSET
  (specific positions poll differently from the area they sit in — background
  checks run 30 points ahead of "gun control").
* An IDEOLOGY COMPASS plots you on fiscal x social, with a gold crosshair
  showing where this district's voters actually sit.
* Quick presets if you'd rather tune from a starting point.

THE LOOP
--------
Build a candidate -> spend action points each week on ads, rallies, ground
game and fundraisers -> survive the weekly dilemmas -> election night.
You start as an underdog nobody has heard of. Name recognition gates
everything: buy reach before you try to persuade.

Hover anything for a tooltip. The menu button in HQ saves;
"Continue" on the title screen reloads. Settings are on the title screen.
