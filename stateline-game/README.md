# Stateline: Campaign Trail

A deep, animated, **native** US political & electoral **campaign simulation game**, built in
**Godot 4.7** (GDScript). Create a candidate, pick a real race, run the trail week by week, survive
the dilemmas, and play out a live election night — all on top of a deterministic voter-behaviour model.

This is the game-engine build of the *Stateline* concept (the `../stateline` folder holds an earlier
TypeScript/React/web prototype). This version is a real desktop game: it exports to a native
Windows/macOS/Linux executable.

![HQ dashboard](../dist/screenshot-hq.png)

## What it is

- **Candidate creator** — procedural portrait, party, point-buy attributes (charisma / competence /
  integrity / fundraising), trade-off background traits, an 8-issue platform, and a choice of **22
  playable races** across the country (House, Senate, Governor, Mayor) at four difficulty levels.
- **Campaign HQ** — an animated district map with a touring campaign bus, a live polling chart with
  margin-of-error band, favourability / name-recognition / cash / momentum gauges, a data-driven
  **action deck** (TV / radio / digital / issue ads, rallies, town halls, canvassing, direct mail,
  fundraisers, polls), hireable **staff**, a **Race Wire** tracking the opposition, and a scrolling
  news ticker.
- **Weekly dilemmas** — 35 authored trade-off events (scandals, endorsements, viral moments,
  deepfakes, disasters, unions, debates…), each mitigated by your candidate's attributes.
- **A real opponent** — the AI runs its own budgeted campaign: advertises, attacks, funds a ground
  game, and responds to the polls.
- **Election night** — precincts report live across the map, a broadcast-style win-probability needle
  swings and settles, vote bars fill, and the race is called (with confetti if you win).
- **Procedural audio** — music beds and SFX synthesized at build time (no external assets), plus
  save/load, a settings screen, and a reduced-motion mode.

## The simulation

A pure, deterministic model (`scripts/Sim.gd`): a jurisdiction's electorate is built from its
demographic segment shares × a calibrated voter-behaviour model (issue positions, salience, partisan
lean/strength, turnout propensity), fit to the race's baseline lean. Vote choice is an
**awareness-gated softmax** over spatial proximity, partisanship, candidate valence and favourability;
turnout scales per segment with a GOTV boost that only lifts a candidate's own supporters. Campaign
actions inject **ramp/decay effects** into a shared ledger. Same seed + same actions → same result.

Demographic figures for real places are **stylized approximations for a game**, not exact Census data.

## Run it

**Play the alpha:** download `StatelineCampaignTrail-alpha-win64.zip`, unzip, run `Stateline.exe`.
(Unsigned build — on the SmartScreen prompt choose *More info → Run anyway*.)

**From source:** open `stateline-game/` in Godot 4.7+ and press Play, or headless:

```bash
godot --path stateline-game            # run
godot --headless --path stateline-game --export-release "Windows Desktop"   # build win64
godot --headless --path stateline-game -- --balance    # print win-rate table
godot --headless --path stateline-game -- --selftest   # simulate one campaign
```

Audio is generated by `tools/gen_audio.py` (pure Python stdlib) into `audio/`; the WAVs are committed
so a fresh clone builds without running it.

## Layout

```
scripts/            autoload singletons: Palette, Content, Sim, Game, AudioBus + UI helpers
scripts/ui/         canvas widgets: MapView, PollChart, Gauge, Needle, Portrait, Ticker, Confetti, BGField
scripts/screens/    Title, Creator, HQ, DilemmaPopup, ElectionNight, Results, Settings
data/               all content as JSON: issues, voter model, districts, dilemmas, headlines, names, copy
audio/              procedurally-generated SFX + music (built by tools/gen_audio.py)
```

## Status — alpha

The full campaign loop is complete and balanced (win rates track the star ratings across the four
difficulties). Not yet built: the debate mini-game screen and the post-win **governing** phase (bill
drafting, whip counts, re-election) — teased on the results screen and next on the roadmap.
